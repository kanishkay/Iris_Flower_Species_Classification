# 🌸 Iris Flower Classification (K-Nearest Neighbors)

📊 A machine learning project focused on classifying Iris flower species using the K-Nearest Neighbors algorithm, achieving perfect accuracy through systematic hyperparameter optimization.

Dataset Overview: The classic Iris dataset contains measurements of sepal and petal dimensions for three Iris species: Setosa, Versicolor, and Virginica. This project demonstrates the complete ML pipeline from exploratory data analysis to model optimization.

Dataset Source: **[Iris Dataset (Kaggle)](https://www.kaggle.com/datasets/uciml/iris)**

📁 Project Structure
* `iris_classification.ipynb`: Main script containing data exploration, visualizations, and KNN implementation with hyperparameter tuning.
* `Iris.csv`: Dataset including four flower measurements (sepal length, sepal width, petal length, petal width) and species labels.

📈 Key Insights
* Predictive Model: Built a K-Nearest Neighbors classifier to accurately distinguish between three Iris species.
* Hyperparameter Optimization: Applied the Elbow Method to identify optimal K value, improving accuracy from 96% to 100%.
* Feature Analysis: Discovered that petal measurements (length and width) show stronger correlation with species classification than sepal measurements.
* Data Preprocessing: Implemented feature standardization using StandardScaler to ensure equal feature contribution to the model.
* Visualization Highlights: Utilized Seaborn and Matplotlib to create correlation heatmaps, pairplots, box plots, and confusion matrix visualizations for comprehensive analysis.
* Model Performance: Achieved perfect classification with 100% accuracy, precision, recall, and F1-score across all species.
